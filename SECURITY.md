# Security Policy

`blender-chatgpt-mcp` controls a local Blender process, so security boundaries matter.

## Credential Policy

This project must not require or store OpenAI Platform API keys. Do not put `OPENAI_API_KEY`, `CODEX_API_KEY`, `CODEX_ACCESS_TOKEN`, ChatGPT session tokens, or personal account credentials in this repository.

The `BLENDER_BRIDGE_TOKEN` value is a local bearer token generated by the Blender add-on. It belongs in a local `.env` file only. `.env` is ignored by git and must not be committed.

## Reporting Vulnerabilities

If GitHub private vulnerability reporting is enabled for the repository, use it for sensitive reports. Otherwise, open a GitHub issue for non-sensitive security hardening topics and avoid including working exploit details or secrets.

## Design Notes

The MVP is local-only:

- The MCP server defaults to `127.0.0.1`.
- The Blender bridge binds to `127.0.0.1`.
- Bridge commands require bearer authentication.
- Tool inputs are schema-validated in TypeScript and validated again in Blender.
- No arbitrary Python, shell, generic Blender operator dispatch, or unrestricted path access is exposed.

This differs from broad Blender Python API MCP servers: this project exposes only allowlisted operations and intentionally avoids LLM-generated code execution.

See [docs/SECURITY.md](docs/SECURITY.md) for the detailed threat model.
